Open infrastructure, not side projects

Cumulative Web Inc builds software the way it builds records: to run the machine. The tools on this page aren’t side projects — they’re the instruments behind the label’s data operation: the Gear Ledger that tracks digital assets, the x402 APIs that let agents pay per call, the ERC-8004 trust layer, the Trust Verdict Checker, KingCode Lens for smart glasses, CWI World Desktop, and the MCP servers that make the catalog machine-readable.

The flagship line is SANQA — six gold-standard instruments for AI agents and the humans who build with them. What’s here on the software page is the wider estate: the trust and utility instruments the machine itself runs on, opened up where they’re useful to builders.

What’s here

Gear Ledger — the provenance ledger for CWI’s digital assets, every item carrying hash-chained proof of use. x402 APIs — machine-payable HTTP APIs over the x402 protocol: agents pay per call, no accounts, no keys to beg for. Trust layer — ERC-8004-based trust primitives plus the Trust Verdict Checker, which scores agent trust deterministically and entirely in the browser. KingCode Lens — web apps for smart glasses, including the simulator lab and voice agent. CWI World Desktop — the desktop environment for the label’s world. MCP servers — including the CWI Discovery Engine, listed on mcprush: the catalog, queryable by any agent.

Frequently asked

Is CWI software free?

The discovery and learning surfaces are free and open — the catalog graph, llms.txt, agent cards. Machine-payable APIs charge per call over x402; the price menu is on the API itself. Nothing here has a subscription trap.

Why does a record label build developer tools?

Because the label’s catalog is consumed by machines as much as humans — playlist algorithms, AI agents, sync databases. Building the tools means owning the rails the music runs on.

Where do I start as a builder?

The MCP server (CWI Discovery Engine) for catalog data, the x402 APIs for paid routes, and SANQA for the flagship suite. The contact page takes technical inquiries through the general path.

Build with it

The fastest on-ramps: query the catalog through the CWI Discovery Engine MCP server, check an agent’s trust through the Verdict Checker (in-browser, nothing uploaded), and read the x402 price menu on the API itself. The estate rewards builders who verify — every instrument here was built to be checked, not trusted.
