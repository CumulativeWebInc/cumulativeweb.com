What is the CWI MCP server and how do I call it?

The CWI MCP server is a read-only Model Context Protocol server that exposes CWI data and tools to AI agents — seven tools, zero dependencies, Node 18 or newer. Clone https://github.com/CumulativeWebInc/cwi-mcp-server and run node server.js; the server speaks stdio to any MCP client.

The seven tools

ledger_state_version, ledger_state_get, ledger_agents, ledger_tasks, ledger_task_get — reads over the public provenance ledger. trust_verdict — deterministic trust scoring that returns insufficient-data instead of inventing a score. needledrop_verify — hash-chain integrity verification for NEEDLE DROP placement ledgers.

How to call it

Stdio (Claude Desktop, Claude Code, Cursor): command node, args [/absolute/path/to/server.js]. Test first — node test.js expects 28/28 passed. HTTP: server-http.js is a streamable-HTTP front end — POST /mcp with JSON-RPC 2.0, stateless, 405 on GET /mcp. Host it yourself; the Dockerfile and Render blueprint ship in the repo, and the repo is the canonical artifact.

Read-only

No write tools, no signing, no state mutation, no secrets in code or logs. 1 MB body cap, 60 requests per minute per IP over HTTP.
