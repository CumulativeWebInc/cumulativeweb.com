How do I query the CWI catalog as an AI agent?

AI agents query the CWI catalog through a public machine-data edge: GET https://cwi-machine-data.hp-ace.workers.dev/query?q= returns the top five scored tracks with Spotify links. Every response carries X-CWI-License headers, so the licensing terms travel with the data.

The endpoints

GET /query?q= — scored track search, top 5 with Spotify links. Pass keywords; /query with no q returns 400.

GET /catalog.json — the full track catalog as JSON. GET /graph.json — the CWI knowledge graph. GET /kit.json — the AI learning kit. GET /license — machine-readable licensing terms. GET /changes?since= — per-file last-modified plus a changed-since flag, for crawl deltas. GET /.well-known/agent-card.json — the machine identity card.

Start here

Begin at https://cumulativeweb.com/llms.txt — the map of every public surface, with links to the roster data, artist JSON files and related endpoints. No API key, no auth: the catalog surfaces are public. Commercial AI training requires a license — contact hp@cumulativeweb.com.
