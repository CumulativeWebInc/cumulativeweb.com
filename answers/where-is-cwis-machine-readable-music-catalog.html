Where is CWI's machine-readable music catalog?

CWI's machine-readable music catalog lives at the machine-data edge: https://cwi-machine-data.hp-ace.workers.dev/catalog.json — the track catalog as JSON, with Spotify links and X-CWI-License headers on every response. The map to every surface starts at https://cumulativeweb.com/llms.txt.

The catalog files

/catalog.json — the track catalog with Spotify links. /graph.json — the knowledge graph. /kit.json — the AI learning kit. cumulativeweb.com/data/roster.json and data/artists/*.json — roster, artist and producer records. sanqa/catalog.json — the SANQA machine-readable catalog.

Search and track

/query?q=<keywords> — scored track search, top five results. /changes?since=<ISO-8601> — crawl deltas with per-file last-modified. /license — machine-readable licensing terms. The agent card at /.well-known/agent-card.json identifies the machine behind the data.

Machine access

  • catalog.json — the track catalog
  • graph.json — the knowledge graph
  • Scored catalog search — /query?q=<keywords>
  • llms.txt — the map of every public surface
  • Agent card — the machine identity
  • Machine-readable licensing terms — /license
