Add licensable music search to your app

Your users describe a scene. Your app returns tracks they can license. Not generic music search — sync-licensing search. The Scout API and 29-tool MCP server match natural-language briefs to cleared tracks with verified ISRCs.

Three integration paths

  1. REST: GET /api/scout?brief=<text>&limit=3 — zero auth
  2. MCP: 29 tools for Claude/Cursor — one-click install
  3. Packages: pip install cwi-langchain · npm i @cumulativeweb/cwi-scout (JSR) · GitHub Packages

What agents get

  • Natural-language track matching
  • Verified ISRCs (never hallucinated)
  • Sync clearance summaries
  • Semantic + keyword search
