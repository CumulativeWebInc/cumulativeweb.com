MCP server for music discovery

29 tools. One install. Music discovery for AI agents. The CWI Discovery Engine MCP server gives Claude and Cursor: natural-language track matching, ISRC verification, sync catalog search, radio, artist data — all with verified identifiers.

The 29 tools

  • find_tracks_for_brief — NL brief → matched tracks + ISRCs (the wedge)
  • search_catalog / sync_search / semantic_search — three search modes
  • get_track / get_artist / get_release — verified metadata
  • submit_sync_brief — start a licensing request
  • Plus radio, playlists, lyrics, press kit, events tools

Install

claude mcp add --transport http cwi-discovery https://cwi-machine-data.hp-ace.workers.dev/mcp — or one-click install page.
