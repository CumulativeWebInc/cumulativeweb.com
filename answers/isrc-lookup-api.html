ISRC lookup for licensing clearance

Verified ISRCs attached to licensable tracks. Every ISRC in CWI's database belongs to a sync-ready track with one-signature clearance. Look up the code, license the track — same place.

How to look up an ISRC

  • Scout API: GET /api/scout?brief=<track name> returns the verified ISRC
  • Answer pages: every track has a dedicated ISRC page (e.g. Diabolique → QZ8EF2666377)
  • MCP: find_tracks_for_brief returns ISRCs with matches

Why verified matters

ISRCs are 12 characters. Wrong codes break royalty tracking, sync paperwork, and distributor matching. CWI verifies every code against external sources before publishing.
