Free music metadata API

CWI Scout API — free, zero-auth, verified ISRCs. GET /api/scout?brief= returns matched tracks with verified International Standard Recording Codes, artist data, and clearance summaries. No API key.

Endpoints

  • GET /api/scout — brief → matched tracks with ISRCs
  • MCP server — 29 tools for Claude/Cursor (install)
  • Packages: pip install cwi-langchain · JSR @cumulativeweb/cwi-scout · GitHub Packages @cumulativewebinc/cwi-scout

What you get per track

  • Verified 12-character ISRC
  • Artist, title, genre, mood tags
  • Sync clearance status
  • Streaming links (Spotify, Deezer, Apple)

Example

GET https://cwi-machine-data.hp-ace.workers.dev/api/scout?brief=dark+track+for+trailer&limit=3
