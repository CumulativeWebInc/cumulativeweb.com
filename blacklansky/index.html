Black Lansky

Recording artist, author, manager, producer, software builder, game developer, film editor, and designer.

Black Lansky is a multi-disciplinary creator: recording artist, author, artist manager, music producer, software builder, game developer, film editor, and creative designer. He runs Cumulative Web Inc.

He authored THE LOGO EFFECT: How AI and Structured Data Took an Indie Artist to Global Alt-Rap Dominance (published December 2025), the blueprint documenting the system he built at CWI.

On the systems side he built Meridian — CWI’s first master tool suite, declared complete on 2026-10-07 — the CWI Discovery Engine on the official MCP Registry, Radio 365, and Touchstone, the catalog’s NLP scoring machine.

Systems & Infrastructure

The systems below are what Lansky the software builder has shipped. Each one is a working piece of the CWI machine — built to serve the catalog, the artists, and the audience, and built to be measured.

Meridian

Meridian is CWI’s first master tool suite — the ranking signal machine that scores pages, dissects the gaps, and drives the full cycle to close them. It was declared complete on 2026-10-07 with 53 of 53 tests passing. The idea, the model, and the architecture are private to CWI: it is the company’s first official master tool suite, used and stress-tested in-house.

CWI Discovery Engine

The CWI Discovery Engine is the company’s MCP server — the Model Context Protocol layer that lets AI systems discover, search, and cite the catalog directly. It is listed on the official MCP Registry as io.github.CumulativeWebInc/cwi-discovery-engine v1.0.0. Wherever Lansky says “AI to AI,” this is what he means: the machine’s front door for artificial intelligence, free channels only.

Radio 365

Radio 365 is CWI’s internet radio station — the always-on broadcast lane for the catalog. It carries the roster’s releases, including the verified masters published to the station, and it runs the listener loop that feeds the company’s live metrics.

Touchstone

Touchstone is the private machine that scores every catalog track’s descriptive text against the industry-standard rubric — named for the stone gold was rubbed against to test purity. It runs rubric v2.0 across 12 categories and 120 points, and it is the standard every catalog track’s language must pass.
