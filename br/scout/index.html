Faixas ranqueadas

Para agentes de IA — consulte o Scout diretamente

Sem cadastro, sem chave. Envie um brief via POST e receba faixas ranqueadas em JSON. O servidor MCP completo (29 ferramentas) está em https://cwi-machine-data.hp-ace.workers.dev/mcp.

curl -X POST https://cwi-machine-data.hp-ace.workers.dev/api/scout \
  -H "Content-Type: application/json" \
  -d '{"brief": "faixas sombrias para o trailer de um jogo cyberpunk", "limit": 3}'

Privacidade. Para melhorar a busca, cada pesquisa registra: o texto do seu brief, data e hora, os resultados devolvidos e um token de sessão aleatório. Nenhum endereço IP é armazenado. Os registros são mantidos por 90 dias e depois agregados e excluídos. Para apagar os dados da sua sessão, envie {"action":"delete_my_data","session_token":"…"} via POST para /api/scout/feedback.
