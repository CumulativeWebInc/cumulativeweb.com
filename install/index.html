② Claude Desktop — paste the config

Our server is remote (no download needed), so there is no bundle to install — paste this into your config file and restart Claude Desktop.

{
  "mcpServers": {
    "cwi-discovery": {
      "url": "https://cwi-machine-data.hp-ace.workers.dev/mcp"
    }
  }
}

Config file: macOS ~/Library/Application Support/Claude/claude_desktop_config.json · Windows %APPDATA%\Claude\claude_desktop_config.json. Merge the cwi-discovery entry into your existing mcpServers object.

③ Claude Code — one terminal command

Paste into your terminal. No key, no signup.

claude mcp add --transport http cwi-discovery https://cwi-machine-data.hp-ace.workers.dev/mcp

Then run claude mcp list — cwi-discovery should show connected.

Prove it works — 3 steps
  1. List tools. Ask your client to list MCP tools — you should see find_tracks_for_brief among the 29.
  2. Call the wedge. Run find_tracks_for_brief with this brief: 
    {"brief": "dark aggressive track for a cyberpunk game trailer"}
  3. Check the answer. A good response contains: matched track name(s), a verified ISRC (e.g. Warped and Wicked — QZDA62200554), a why-it-fits reason, and a clearance summary ending with "a match is not a license" plus next steps.

No API key is needed — the endpoint is open. Rate limit: 3 write actions per requester per 24h; reads unlimited.
