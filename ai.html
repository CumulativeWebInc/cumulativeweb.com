Give Your AI a Record Label

The CWI Discovery Engine is an MCP server with 29 tools: indie game & film sync licensing with real ISRC records, live Radio 365, catalog search, lyrics, press kit, and more. Install it in your AI client in under a minute.

Claude Desktop

Paste this into your claude_desktop_config.json:

{
  "mcpServers": {
    "cwi-discovery": {
      "command": "npx",
      "args": ["-y", "@smithery/cli@latest", "run", "io.github.CumulativeWebInc/cwi-discovery-engine"]
    }
  }
}

Cursor / Windsurf

Run this one-liner in your terminal:

npx -y @smithery/cli@latest run io.github.CumulativeWebInc/cwi-discovery-engine --client cursor

Try it — 3 prompts to paste once installed

  1. "Search the CWI catalog for high-energy alternative rap tracks suitable for an action scene."
  2. "Pull the complete metadata, ISRC, and sync clearance terms for Cyberpunk 2027."
  3. "What is currently playing on Radio 365, and what's on the upcoming schedule?"

What you get

29 tools across 7 lanes: catalog search, semantic search, track/artist/genre lookup, knowledge graph, live radio (Radio 365), sync licensing search with machine-readable license terms, playlist data, release packets, videos, lyrics, press kit, events — plus song requests, airplay submissions, sync briefs, playlist pitches, event RSVP, and one-call sync-track matching (find_tracks_for_brief).

No API key. No auth. Free.
