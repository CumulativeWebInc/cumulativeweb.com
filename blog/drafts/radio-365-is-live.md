# Radio 365 is live

Radio 365 — Cumulative Web Inc's 365-day station for independent artists — is now streaming at [cumulativeweb.com/radio.html](https://cumulativeweb.com/radio.html).

The station broadcasts the CWI catalog over [HLS](https://cumulativeweb.com/radio/hls/program.m3u8), and a live [now-playing feed](https://cumulativeweb.com/radio/now-playing.json) publishes the current track, artist, and artwork in real time. The 7-day program playlist is published alongside the stream, so the full week's rotation is machine-readable too.

This is the station the [launch announcement](https://cumulativeweb.com/press/releases/cumulative-radio-365-launch.html) described: a full parallel to the old broadcast setup, rebuilt to stream from our own infrastructure — no rented computer, nothing to suspend.

Every track in rotation also has a machine-readable page in the [CWI learning index](https://cumulativewebinc.github.io/cwi-learn/tracks/), with cite-ready references and equip commands for AI agents.

Tune in: [cumulativeweb.com/radio.html](https://cumulativeweb.com/radio.html).
