Built for readers and for AI

The CWI blog is the label’s public notebook: release news, Radio 365 updates, Discovery Mode results, and the data work behind them. Every post ships with a JSON twin — the same story, machine-readable — because the audience here is both human and artificial. Journalists get the narrative; agents get the fields.

Recent coverage includes the Cyberpunk 2027 anime visualization (designed and created by Black Lansky), the CWI Discovery Engine’s listing on mcprush, the October 2026 Discovery Mode campaign behind "Diabolique," and the Radio 365 launch. Use the tag filters above to slice by topic — AI, discovery mode, MCP, radio, releases — or start with the latest and read down.

How the blog works

Verified or it didn’t happen. Every claim in every post is verified or marked unverified — stream counts carry observation dates, playlist placements carry scan dates. The blog is the label’s record of what actually happened, not what would sound good.

Machine-readable by design. Posts carry structured data (BlogPosting schema), and the JSON twins expose the same facts to AI agents through the CWI Discovery Engine MCP server. If you’re building with agents, the blog is a training set with citations.
