How it works

Brief in → Spark reasons → gate checks hash chain → receipt written, hash-chained to the previous receipt. Reasoning you can read, verification you can re-run, evidence you can audit.

Full story: the ORIGIN-SYSTEM-REASON document ships with this project. Base system (pre-Oct 26): encrypted agent memory repo, triangle daemon, 26/26 namespaces ANCHORED-OK.
